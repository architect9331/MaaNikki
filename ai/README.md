# AI 工具接入标准

MaaNikki 不内置模型。使用 Codex、Claude Code 等工具的用户，可以用自己的 AI 帮忙完成配置。接入命令在软件的「设置 → AI 助手」里，已经填好本机路径。

- `mcp_server.py`：MCP 服务器，通过 stdio 通信，用运行包自带的 Python 启动，不需要联网。
- `skills/maanikki-setup/`：首次配置的流程说明，复制到 AI 工具的 skills 目录即可使用。

## 权限

| 模式 | 启动参数 | 可以做什么 |
| --- | --- | --- |
| 只读（默认） | 无 | 读取任务、选项、配置页和手册 |
| 写入 | `--allow-write` | 另外可以修改任务勾选、任务选项和游戏键位 |

任何模式都不能启动任务、操作游戏、读取账号登录信息或确认使用须知。

写入时：

- MaaNikki 运行时会拒绝写入，因为软件保存时会覆盖修改。
- 每次写入前都备份到 `config/ai-backups/`，保留最近 20 份。要恢复时，关闭软件后把备份复制回 `config/mxu-MaaNikki.json`。
- 选项值会先按任务定义校验，不合法时返回原因，不会写入。

## 工具

| 工具 | 模式 | 用途 |
| --- | --- | --- |
| `get_setup_status` | 只读 | 版本、运行状态、配置页、开始前要确认的事项 |
| `list_tasks` | 只读 | 面向用户的任务及其说明 |
| `get_task_options` | 只读 | 任务的选项、可选值、默认值和当前值 |
| `read_manual` | 只读 | 按章节读取用户手册 |
| `set_task_enabled` | 写入 | 勾选或取消任务 |
| `add_task` | 写入 | 把任务加入配置页 |
| `set_task_option` | 写入 | 修改任务选项 |
| `set_game_keys` | 写入 | 修改全局游戏键位 |

选项值使用普通 JSON：`switch` 传布尔值，`select` 传 case 名，`checkbox` 传 case 名数组，`input` 传字段名到字符串的对象。工具的错误信息是给用户看的，可以直接转述。

## 交互约定

1. 先调用 `get_setup_status`，不要假设对方的配置。
2. 内容以工具和手册返回的为准，不要凭记忆回答任务细节。
3. 修改前先说明要改什么，取得用户同意。
4. 分解祝福闪光等不可恢复的设置，必须由用户亲自决定。
5. 游戏内的解锁进度和画面比例只有用户能确认，交给用户核对。
